## Environment and architecture

Verification ran on Darwin arm64 with Node 24.17.0, npm 11.13.0, local uv 0.10.6, and Docker 29.8.0. The API container pins uv 0.12.16 and Python 3.12; the web container uses Node 24. Next.js 16.3.6 and React 19.3 render the editorial pages. The same-origin Next contact route calls a private FastAPI service, which validates and commits inquiries to PostgreSQL. Optional SMTP notification runs after the response; committed records remain `pending` if delivery fails. Compose exposes only the web service on localhost for a future trusted TLS proxy.

## Security, accessibility, and performance status

The implemented controls cover bounded input, authoritative API validation, same-origin checks, a private API token, database-backed throttling, a honeypot, safe errors, nonce CSP, secure headers, request IDs, and logs that omit full contact messages and email addresses. OWASP ASVS 5.0 informed the threat model; no compliance certification is claimed. A trusted reverse proxy must overwrite client-IP headers for rate limiting to be reliable in production.

Automated accessibility and keyboard checks passed. A human screen-reader session and testing on physical devices remain to be completed before an unconditional accessibility claim. The design respects reduced-motion settings. Local Lighthouse LCP/CLS and transfer budgets passed; INP and field LCP/CLS require real-user measurements after deployment.

## Deployment status and known limits

No public portfolio deployment or GitHub Actions run has occurred for this revision. The local repository has an `origin` remote configured but no push was performed. Before production launch, supply and verify the canonical domain, DNS/TLS and trusted proxy, production PostgreSQL credentials and backups with restore drill, secret storage, SMTP or a staffed pending-inquiry process, log sink/alerts, retention scheduler and backup expiry, social preview on the real origin, and field performance. The deployed privacy notice must reflect the actual retention schedule.

The email task is best effort within the API process, not a durable queue. A crash after commit can leave a record `pending`; the operator CLI provides recovery visibility. Simultaneous first submissions for one rate-window key can produce one transient 503 due to a uniqueness race; an atomic upsert should replace this if observed in production.
