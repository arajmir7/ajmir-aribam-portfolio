## Brand and copy decisions

The existing paper/graphite, cobalt, emerald and copper system remains coherent across light and dark themes. New project diagrams use restrained project-specific accents while preserving the site’s typography and spacing. The public name is exactly **Ajmir Aribam**.

The copy describes the work that source supports: server-owned totals, evidence-linked review, deterministic accessibility checks, civic workflow design and local prototype boundaries. It excludes unsupported school figures, business outcomes, production AI accuracy, legal authority, and private source paths. Social links use the supplied GitHub, LinkedIn, Instagram and X URLs.

The user-supplied Verity, SCMIRN, AccessForge and Zam Zam captures were reviewed as visual evidence. The portfolio uses clean native diagrams for the new case hero surfaces so browser chrome and inaccessible attachment paths are not shipped as site assets.

## Release boundary

The local candidate can be rebuilt and run with the repository’s existing Compose topology. Production still requires the final HTTPS origin, proxy/IP policy, database credentials and restore-tested backups, secret storage, staffed inquiry delivery or SMTP, retention scheduling, alerts, live-origin metadata review, human accessibility review and field monitoring. No push or deployment is part of this review.
